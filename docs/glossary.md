# Glossary

Technical term definitions for the CyberSec AI Platform.

---

| Term | Definition |
|------|------------|
| AES | Advanced Encryption Standard. Symmetric block cipher used in the Encryption Sandbox (F-12). Modes: CBC and GCM |
| APK | Android Package Kit. Android application archive format. Scanned for malware by F-08 |
| AST | Abstract Syntax Tree. Structural code representation used by the SAST pipeline in Secure-Coding Assistant (F-18) |
| ATT&CK | Adversarial Tactics, Techniques and Common Knowledge. MITRE knowledge base of adversary behaviors. Powers F-30 |
| Binary Search | O(log n) sorted-list search algorithm. Used in the breach hash prefix database (F-09) |
| Bloom Filter | Space-efficient probabilistic data structure for set-membership testing. Provides O(1) miss detection in breach engine (F-09) |
| CORS | Cross-Origin Resource Sharing. Browser policy controlling cross-domain HTTP access. Auto-patched by Remediation Engine (F-17) |
| CSPRNG | Cryptographically Secure Pseudo-Random Number Generator. Provides unpredictable random bytes for password generation (F-10) |
| CSP | Content Security Policy. HTTP response header restricting allowed content sources. Mitigates XSS. Auto-generated by F-17 |
| CTF | Capture The Flag. Competitive cybersecurity challenge format with hidden flags. Implemented in F-28 |
| CVE | Common Vulnerabilities and Exposures. Standardized identifier for publicly known vulnerabilities. Used in F-16, F-30 |
| CWE | Common Weakness Enumeration. Categorization system for software security weaknesses. Used by Remediation Engine (F-17) |
| DAST | Dynamic Application Security Testing. Black-box security testing against a running application. Core of F-16 |
| dHash | Difference Hash. Perceptual hash computed by comparing adjacent pixel brightness values. Used in Digital Content DNA (F-05) |
| DMARC | Domain-based Message Authentication Reporting and Conformance. Email authentication protocol. Annotated by DNS Explainer (F-19) |
| EfficientNet-B0 | Compact and efficient convolutional neural network. Performs per-frame deepfake classification in F-01 |
| ELA | Error Level Analysis. Image forensics technique detecting pixel edits via JPEG compression artifact differences. Used in F-04 |
| EXIF | Exchangeable Image File Format. Standard metadata embedded in image files (GPS, device, timestamps). Handled by F-11 |
| FAISS | Facebook AI Similarity Search. High-performance vector similarity search library. Powers RAG retrieval in AI Mentor (F-26) |
| FFmpeg | Open-source framework for video recording, conversion, and streaming. Used in frame extraction (F-01) and video compositing (F-25) |
| FIR | First Information Report. Formal police complaint document in the Indian legal system. Generated by Case Filing engine (F-20) |
| HIBP | Have I Been Pwned. Public breach intelligence service providing SHA-1 hash prefix lookup. Referenced by F-09 |
| Homograph Attack | Phishing technique substituting ASCII letters with visually similar Unicode characters to create lookalike domains. Detected by F-02 |
| HSTS | HTTP Strict Transport Security. Response header forcing HTTPS connections. Checked by Puspajeet SSL scripts and F-16 |
| k-Anonymity | Privacy model guaranteeing each record is indistinguishable from at least k-1 others. Core protocol of Breach Check Engine (F-09) |
| LangChain | Python framework for building LLM-powered RAG pipelines and autonomous agents. Core of AI Cyber Mentor (F-26) |
| MITRE | Nonprofit organization maintaining the CVE program and ATT&CK adversary behavior framework |
| MTCNN | Multi-task Cascaded Convolutional Networks. Real-time multi-stage face detection and alignment. Used in F-01 |
| NLP | Natural Language Processing. AI techniques for text understanding, classification, and generation. Used in F-03, F-06, F-14 |
| Nuclei | Open-source DAST vulnerability scanner by ProjectDiscovery using community YAML templates. Core of F-16 |
| NVD | National Vulnerability Database. NIST-maintained CVE repository with CVSS scoring. Feeds Threat Intel Hub (F-30) |
| OCR | Optical Character Recognition. Extracting machine-readable text from images. Used in F-04, F-11, F-24 |
| OWASP Top 10 | Open Web Application Security Project list of the 10 most critical web security risks. Framework for F-16 |
| pHash | Perceptual Hash. Image fingerprint based on DCT frequency domain, robust to minor visual edits. Used in F-05 |
| Quishing | QR code phishing. Embedding malicious URLs in QR codes to bypass link-based email filters. Addressed by F-07 |
| RAG | Retrieval-Augmented Generation. LLM architecture retrieving relevant documents from a vector store before generating answers. Core of F-26 |
| RSA | Rivest-Shamir-Adleman. Asymmetric public-key encryption algorithm using prime factorization. Demonstrated in F-12 |
| SAST | Static Application Security Testing. Analyzing source code for vulnerabilities without executing it. Implemented in F-18 |
| SHA-1 | Secure Hash Algorithm 1. 160-bit hash function. Used for k-Anonymity breach prefix lookup in F-09 |
| SHA-256 | Secure Hash Algorithm 256-bit. Cryptographic hash used for file integrity verification in F-05 and F-13 |
| SM-2 | SuperMemo 2. Spaced repetition scheduling algorithm computing optimal review intervals from recall quality ratings. Used in F-29 |
| SPF | Sender Policy Framework. DNS TXT record specifying which mail servers may send email for a domain. Explained by F-19 |
| TLS | Transport Layer Security. Cryptographic protocol for HTTPS. Inspected by F-07, audited by Puspajeet scripts |
| TTS | Text-to-Speech. AI synthesis of natural-sounding spoken audio from text. Used in video generation pipeline (F-25) |
| VirusTotal | Google-owned service aggregating 70+ antivirus engines for file and URL analysis. Integrated in F-08 |
| XSS | Cross-Site Scripting. Code injection attack inserting malicious scripts into web pages. Detected by F-16, explained by F-18 |
| zxcvbn | Open-source password strength estimation library by Dropbox. Simulates dictionary and pattern attacks. Used in F-10 |
