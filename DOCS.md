For any digital artifact, log file, or forensic screenshot to be admissible in Indian courts, it must be accompanied by an Electronic Evidence Certificate signed by the person in lawful custody of the computer resource.

**k-Anonymity Cryptographic Architecture:**
TRINETRA implements mathematical k-Anonymity via the browser's native WebCrypto API:
1. The user's password is encrypted locally into an SHA-1 160-bit hex digest (e.g., `5BAA61E4C9B93F3F0682250B6CF8331B7EE68FD8`).
2. The engine splits the hash into a 5-character prefix (`5BAA6`) and a 35-character suffix (`1E4C9B93F3F0682250B6CF8331B7EE68FD8`).
3. Only the 5-character prefix (20 bits of entropy) is transmitted to the remote breach API. The API returns a bucket of ~500 matching hashes.
4. TRINETRA searches the received bucket locally in memory. The user's plaintext password and full hash never touch the network.

   - `fir_dossiers` table: storing generated FIR JSON, police station jurisdiction, and generated PDF blobs;
   - `evidence_vault` table: storing hashes, URLs, payload metadata, and EXIF extraction logs.

When a user clicks 'Generate FIR', the backend returns `job_id: 'fir_8293'` with a 202 Accepted status. The frontend listens via Server-Sent Events (SSE) or WebSockets with progress indicators:
   `[1/3] Classifying Offenses...` -> `[2/3] Mapping BNS Sections...` -> `[3/3] Generating Cryptographic PDF`.

3. **BSA 2023 Section 63 Digital Evidence Certification**: Indian courts require an electronic evidence certificate for any digital record to be admissible in a court of law. TRINETRA will automatically generate a BSA Section 63 Digital Evidence Certificate bundled with every FIR PDF, including:
   - SHA-256 hash of all uploaded screenshots, logs, or chat transcripts;
   - Exact server UTC and IST timestamps synchronized with National Physical Laboratory (NPL) NTP servers (mandated by CERT-In);
   - Cryptographic hash of the output PDF to guarantee chain-of-custody.

4. **RAG Legal Grounding Pipeline**: Boost legal precision from 60% to 99% by attaching a vector search index containing:
   - Bharatiya Nyaya Sanhita (BNS 2023 Full Gazette),
   - Bharatiya Nagarik Suraksha Sanhita (BNSS 2023),

   - Information Technology Act 2000.

5. **Three-Tier Role-Based Access Control (RBAC)**: Enforce three permission tiers:
